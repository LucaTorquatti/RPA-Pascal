Tema 4: Repetición Incondicional.

Tema 5: Repetición Condicional.

Tema 6: Condiciones por casos.

Tema 7: Creando nuevas primitivas: funciones y procedimientos.

Tema 8: Resolución de problemas por descomposición y composición.

Tema 9: Resolución de problemas usando recursión.
